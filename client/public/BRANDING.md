# HCMUT logo

`hcmut-logo.png` is the original 1208 × 1220 PNG supplied for BKQuiz.
It replaces the hand-drawn approximation in `BKLogo` and the favicon.
The image is unchanged; CSS scales it proportionally with `object-contain`.

- Source: https://commons.wikimedia.org/wiki/File:HCMUT_official_logo.png
- Author listed on the source page: Nuocmatchobinhminh
- License listed on the source page: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)

The logo is served locally so it does not depend on an external image host.
